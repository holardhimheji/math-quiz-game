# Math Quiz game 

A simple and fun math quiz game built with HTML, CSS, and Vanilla JavaScript.

It generates random math problems using `+`, `-`,'/' and '*' and checks if your answer is correct.

## 🚀 Features
- Generates random math questions
- Supports Addition, Subtraction, Multiplication and division 
- Instant feedback (Correct / Wrong)
- Responsive and centered design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript 

## 📂 How It Works
1. Click **Generate** to get a random question like `5 + 7 = ?`
2. Type your answer and click **Submit**
3. Get your result
4. Click **Next** to return to the start and play again
